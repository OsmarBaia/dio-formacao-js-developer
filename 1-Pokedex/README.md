# Pokedex
## Objetivo
O objetivo dessa atividade foi reproduzir o design de uma Pokédex com base no modelo fornecido, o qual consiste de duas telas, uma de listagem e uma de detalhes. A estilização da listagem de Pokémon foi adaptada para melhor visualização do texto no mobile e responsividade em telas grandes. Além disso, foi implementada a integração com a PokeAPI, utilizando requisições HTTP para consumir dados dos Pokémon, a manipulação do dados, criação de elementos e estilização deste foram feitas no JavaScript, o qual é também  responsável pela inserção destes elementos na DOM, também criei um mecanismo de rolagem "infinita" para paginação, busca por nome e filtragem por tipo.
